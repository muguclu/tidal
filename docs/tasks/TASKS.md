# TASKS — Tidal backlog

Status legend: `todo` · `doing` · `review` · `done` · `blocked` · `superseded`
Columns: **Wave/Lane** (see PARALLELISM.md) · **Deps** (must be `done`) · **Owns** (only files this
task may create/modify; `+tests` = matching files under `tests/`).
Every task's PR must reference its ID and tick its "Done when" items.
**Shared files** (`pyproject.toml`, `uv.lock`, `Makefile`, `tests/conftest.py`, `docs/finops/cost-model.md`)
are owned by T-001/T-126 and afterwards changed only by the orchestrator between merges (PARALLELISM §1.7).
Tasks that add Azure resources write `docs/finops/deltas/T-xxx.md` instead of editing the cost model.
`NEEDS-CLOUD` in a Done-when = executed in the cloud window, not blocking the gate (PLANNING §4).
