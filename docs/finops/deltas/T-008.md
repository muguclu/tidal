# Cost delta T-008 (Terraform bootstrap + CI OIDC)

| Resource | SKU | Estimate EUR/month (active) | Parked | Lever |
|---|---|---|---|---|
| Terraform state storage account `rg-tidal-tfstate` | StorageV2, Standard LRS, Hot | < 0.01 | < 0.01 | none needed |
| Entra app / SP `sp-tidal-ci`, federated credentials | Entra (included) | 0 | 0 | none |
| Role assignment | included | 0 | 0 | none |

**Delta: < 0.01 EUR/month** (planning estimate; to be replaced by a measured Cost Management value).
State is a few KB per env. Even with versioning and 7 d soft delete retention, volume stays well under 1 MB,
and Hot LRS at about 0.02 EUR/GB-month is far below a cent. Transaction costs for occasional plan/apply runs are negligible.

SKU justification:
- LRS, not GRS/ZRS: the state is re-creatable from code and history is protected by versioning plus soft delete.
  GRS would roughly double a cost that is already rounding error but add no recovery path we would use.
- Hot, not Cool: state blobs are read and written on every plan; Cool adds read charges and an early-deletion window.
- Infrastructure (double) encryption is enabled; it has no price.
- Not parked: bootstrap must survive `make park` and `terraform destroy` of any env, at negligible cost.
