## Decisions and levers

- **No second action group, no second budget alert.** `modules/budget` already creates `ag-tidal-<env>` and a 50/80/100 % actual plus
  100 % forecast budget; the SPEC-10 "budget 80 %" alert is that 80 % notification.
- **Rule frequency is the only per-rule cost lever.** 5xx is 5 min (0.132, three times a 15 min rule) because a 10 minute error window
  is the SPEC; everything else is 15 min or slower.
- **Blob audit is a flag** (`enable_blob_audit`). Off saves the ingestion but loses the SetBlobTags/DeleteBlob signal. The diagnostic
  setting logs write and delete categories only; StorageRead is excluded on purpose (volume against the cap, no tamper signal).
- **Spot eviction rule** needs Container Insights (`enable_container_insights`, off in dev for cost). Enabling that is a separate
  cost decision; this module only follows it (`container_insights_enabled`).
- **Entra-only App Insights** has no cost effect.
