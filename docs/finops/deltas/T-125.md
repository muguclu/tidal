# Cost delta T-125 (budget module)

Status: DOCUMENTED (no price meter exists). Delta: **EUR 0.00 per month**.

Resources: `azurerm_monitor_action_group` (email receivers), `azurerm_consumption_budget_resource_group` /
`_subscription`, optional `azurerm_cost_anomaly_alert`.

## Evidence

- `docs/finops/prices.yaml` (captured 2026-10-21, EUR) has no meter for budgets, cost alerts or action groups; the
  only Azure Monitor entry is Basic Logs ingestion, unrelated. These features are not billed through the Retail
  Prices meters, so there is nothing to model.
- Azure documentation: Cost Management budgets and cost alerts are free ("Cost Management features are available at
  no cost" for Azure-native cost analysis, budgets, anomaly alerts). Azure Monitor pricing lists email
  notifications in action groups as free (first 1,000 emails per month are free, and the overage is
  USD 2 per 100,000 emails); SMS, voice and push have charges. This module configures **email receivers only**.
- Expected volume is a handful of emails per month (4 budget thresholds plus alerts from T-506), far below the
  1,000 free emails.

## Levers and risk

- Adding `sms_receiver` or `voice_receiver` later would add per-message charges; not done here.
- The budget does not stop spend; it only notifies. Enforcement is `make park` (SPEC-07).
