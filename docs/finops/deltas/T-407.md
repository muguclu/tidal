
The dev default (A) uses under 0.1 % of the 0.2 GB/day workspace cap and stays inside the 5 GB/month free tier. The cap is
the ceiling: it already sits in the cost model as 2.63 EUR/month for all sources. Cost delta: **0.00 EUR/month**. Risk: a
chatty action group (C) uses about 20 % of the cap and could starve App Insights data; hence the low-volume default and the
`audit_action_groups` variable. Retention is the workspace retention (30 days).

## Auto-pause

Audit events are written by the engine when sessions run; auditing does not open connections, so it should not hold the
database awake. Not verified (no Azure access): confirm on the first dev apply that the database still pauses after 60
idle minutes with auditing on. Defender and VA scans do wake or hold a database, which is a second reason they are off.
