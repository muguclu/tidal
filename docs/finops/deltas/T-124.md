# Cost delta T-124 (servicebus module)

Status: MODELLED from `docs/finops/prices.yaml` (captured 2026-10-21, EUR, westeurope) via
`tidal.finops.fetch_prices.load_prices`. No measurement yet.

Resources: `azurerm_servicebus_namespace` (Basic by default), three queues (`backtest-jobs`, `backtest-results`,
`tiering-jobs`; queues have no charge of their own on Basic). With `enable_ingest_topic = true`: namespace becomes
Standard, plus topic `ingest-events` and subscriptions `stats`, `quality-alerts`.

## Basic: operations only

Basic has no base charge, only the "Basic Messaging Operations" meter (`servicebus_basic_ops_1m`).

```python
pb = load_prices("docs/finops/prices.yaml")
p = pb.unit_price("servicebus_basic_ops_1m")   # 0.044 EUR per 1M operations
```

Assumptions (stated, not measured): one operation = one send, receive or complete. Per backtest child job:
send + receive + complete on `backtest-jobs`, same three on `backtest-results`, plus about 2 lock renewals for
a job running over 5 min = **8 operations per job**. Sweeps are 100 jobs. KEDA queue-length reads use the
management API and are assumed not billed as messaging operations (to verify on first Cost Management read).
Tiering jobs are a handful per month and are ignored.

| Case | Jobs/month | Operations | EUR/month |
|---|---|---|---|
| Light: 4 sweeps x 100 jobs | 400 | 3,200 | **0.0001** |
| Heavy: 30 sweeps x 100 jobs | 3,000 | 24,000 | **0.0011** |
| Break-even for 1 EUR | n/a | 22.7 million | 1.00 |

Cost is effectively 0 (consistent with the cost-model.md row "Service Bus Basic < 1"). Nothing to park:
no operations when idle.

## Standard (only when `enable_ingest_topic = true`)

Standard adds a fixed monthly base charge per namespace plus a per-operation meter. **The Standard base-charge meter
and the Standard operations meter are NOT in `docs/finops/prices.yaml`**, so no EUR figure is stated here. Action for
the finops-analyst (T-501 meter list): add the Service Bus Standard "Base Unit" and "Standard Messaging Operations"
meters, then fill this section. Until then the flag stays default false (ADR-0003) and the cost-model.md
row is unchanged. Qualitatively: the jump is from 0 fixed to a fixed monthly charge that accrues even when idle
and is not removable except by destroying the namespace, so the flag should be on only for Phase 5 demos.

## SKU justification and levers

- Basic: cheapest SKU that has queues, DLQ, lock renewal and TTL (ADR-0003). No sessions, no duplicate detection,
  no topics, no private endpoint (ADR-0006).
- Levers: `enable_ingest_topic` (Basic to Standard), per-queue `default_message_ttl` and `max_delivery_count`
  (fewer redeliveries means fewer operations).
