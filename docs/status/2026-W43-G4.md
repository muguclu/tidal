## Gaps found (no item FAILs, but these are real)

1. **R-26, fix before the first deploy.** The namespace bootstrap breaks the PSA guarantee. The chart defaults to
   `namespace.create: true`, but `docs/runbooks/deploy.md:70-76` has the human run a bare `kubectl create namespace tidal`
   (no PSA labels), and `sp-tidal-deploy` only has namespace-scoped RBAC Writer. The first `helm upgrade` should fail; the
   obvious workaround (`create=false`, `externallyManagedAck=true`) runs the worker in a namespace without PSA `restricted`.
   Fix: label the namespace in the runbook command and set `create: false` + `externallyManagedAck: true` in `values-dev.yaml`.
   Verify live.
2. **R-20.** The admin routes are in the contract but not implemented, and no task owns them (checklist item 4, half).
3. **R-19.** kube-linter/kubeconform are not in CI. `deploy/helm/tidal/.kube-linter.yaml` and `docs/runbooks/images.md:51`
   claim they are. The chart unit test does not check privileged/hostPath and skips without Docker.
4. **R-18.** `sp-tidal-ci-plan` is created by hand, outside Terraform and outside the drift baseline.
5. Nit: the `.gitleaks.toml` path allowlist `^docs/finops/prices\.yaml$` only matches in git mode, so a `gitleaks dir` scan
   reports 3 false positives. A `(^|/)docs/finops/prices\.yaml$` pattern would cover both modes.
